V33 PERFORMANCE QA

Changes:
- Dynamic active/idle render rate: full responsiveness while interacting, lower FPS when the city is idle.
- Cars/pedestrians/night traffic update at a fixed lower simulation rate instead of every rendered frame.
- Camera smoothing is frame-rate independent and faster; projection matrix updates only when zoom actually changes.
- Camera HUD DOM updates only when the displayed percentage changes.
- Pointer-to-ground math reuses a THREE.Vector2 to reduce garbage collection during drags.
- Removed unnecessary material.needsUpdate calls during Day/Night transitions.
- Section navigation NodeLists are cached instead of queried on every open/close.
- Portfolio DOM templates warm almost immediately after city entry; media preloading waits longer and runs more conservatively.
- Service worker V33 caches same-origin assets and the pinned Three.js CDN file on controlled repeat visits.
- Service-worker warmup is serial/low-priority to avoid competing with interactions.
- Hosted actor counts are slightly reduced without changing the layout.
- Mobile mountain detail reduced modestly; instanced mountain bounds allow normal frustum culling.
- Three.js preload hint starts the CDN request earlier during HTML parsing.

Validation performed:
- node --check on main.js, runtime.js, world-boundaries.js, sw.js
- duplicate HTML ID check
- version-reference consistency check
- CSS brace balance check
